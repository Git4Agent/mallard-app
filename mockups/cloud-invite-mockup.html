The invitation code panel

The Members tab of a private repository, as an Owner or Admin sees it. Everything above the panel is the shipped stylesheet; each direction is drawn in the panel's four states. The code is fixture-shaped (K7PQM-3HWXR-TN9FD-2BZCE: 20 characters with no 0, O, 1, I, L or U) and, as in the service, it can be read only in the moment it is created.

#before #a #b #c

Before · as shipped

Two paragraphs of policy before any state; the code, the one thing that matters, arrives last as a green notice under the buttons.

A · The code is the panel's face

Four ink cells hold the code in every state: empty dashes, the code itself, or dots once it is hidden. One line says what is true now; the policy folds into How codes work.

B · A ticket row

One compact row states Open or Closed with who and when, beside its buttons. A new code tears off below the row as a honey stub and goes away with Done.

C · Two steps

A single line while there is nothing to hand over. Creating or rotating opens the panel into a hand-off: the code in a copy field, and where the other person enters it.
