A box per repository

The same twelve rows that are live now, and the same row markup — every rule under .repo-row below is lifted from the shipped stylesheet. Only the box around each row changes between the three.

Ten of the twelve have no description, so most rows are two lines. That is what decides how a box reads: a heavy box around a two-line row is a lot of furniture for very little content, which is what D3 answers.

Where I would land

D3. Boxing costs vertical space, and at twelve rows where ten carry no description, D1 spends that space on emptiness — a bordered, shadowed box wrapped around a name and a date. Folding the bare rows onto one line keeps the product's own box grammar while making the list shorter than it is today, not longer. D2 avoids the weight instead of earning it, and stops looking like the rest of the site.

If descriptions become common later, D3 degrades into D1 by itself: every row that gains a description stops folding.
