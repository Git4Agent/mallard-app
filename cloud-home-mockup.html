A One list GitHub's repositories page

Everything in one tile: a tab strip for All · Yours · Public, a search box, and dropdown chips for class, provider, kind, and sort, exactly where GitHub puts Type / Language / Sort. Your repositories are marked in the shared list instead of living in a second panel; anonymous visitors see the same page minus the Yours tab.

  • One thing to read. No second panel, no rail; the page is a list.
  • Filters cost nothing until used. Chips stay one line; a chip opens a small menu with counts.
  • Same page signed in or out. The Yours tab is the only difference.
  • Counts are hidden. Facet counts live inside the chip menus rather than on the page.

B Rail, one list Hugging Face's hub listing

C Cards Hugging Face's model cards

A two-column grid of compact cards under one chip row. Each card is name, kind, a one-line description, and a metric line; yours carry a mark. Hugging Face lists models this way because a grid shows twice as many items per screen as rows and reads as a catalog rather than a table.

  • Densest. Ten repositories fit above the fold.
  • Reads as a catalog. Skills and pets sit naturally in cards.
  • No panels inside panels. One tile, one grid.
  • Weaker scan for projects. Session and file counts are easier to compare down a column of rows.
